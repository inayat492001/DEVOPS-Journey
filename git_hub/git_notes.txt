1) Working Directory :
=> This is the directory when you actually create & modify files.
Ex: my_project/
       |_ app.txt
       |__index.html
       |_ app.js
The change is currently in your working directory.

2) Staging is the stage where you decide which changes should be included next

* .git/ (Hidden Folder)

It contains information that Git needs to manage the repo including History and internal repo data.

* git add filename (To track specific file)
*git add. (To track all files)
*git config --global user.name "user name"
*git config --global user.email "emailid@gmail.com"
To check config => git config --global --hit

3) Local Repository:
=> It is the stage where you permanently record the staged changes as a commit/
